# boltipv6

Bolt URLs and ipv6 query parts with stable normalization.

**Site:** https://theworker02.github.io/boltipv6/

## Install / run

```bash
git clone https://github.com/theworker02/boltipv6.git
cd boltipv6
node src/cli.js
node --test
```
